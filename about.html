О проекте

ShopProject — учебный интернет-магазин, созданный в рамках дисциплины «Фронтенд и бэкенд разработка». Это многостраничный сайт, на котором отрабатываются семантическая разметка, CSS-оформление, состояния интерфейса, Flexbox и CSS Grid.

Наша цель

Показать, как создается современный многостраничный сайт.

Что использовалось

  • семантическая HTML-разметка;
  • CSS-переменные и состояния интерфейса;
  • Flexbox и CSS Grid для раскладки;
  • методология БЭМ для именования классов;
  • Git и GitHub для контроля версий;
  • GitHub Pages для публикации сайта.
